# 体重とサプリ

毎日の体重と、朝・昼・晩のサプリを記録するWebアプリ。iPhoneのホーム画面に追加するとアプリのように使えます。

**公開URL: https://tatsuyaishizukaai-hash.github.io/diet-log/**

## ホーム画面への追加

1. iPhoneのSafariで上のURLを開く
2. 下の「共有」ボタン →「ホーム画面に追加」
3. 以後はホーム画面のアイコンから開く（一度開けばオフラインでも使えます）

記録は端末の中（localStorage）だけに保存されます。サーバーには何も送りません。そのため端末ごとに別々の記録になり、Safariのタブとホーム画面のアプリでも保存先が分かれます。**記録はホーム画面のアイコンから開いて付けてください。**

## できること

- **サプリ** — 朝・昼・晩のフタをタップして記録。時刻が残り、もう一度タップで取り消し。下の7日分のミニケースで飲み忘れが一目でわかり、過去の日も直せる
- **飲み忘れ・測り忘れバナー** — 朝10:30／昼14:00／晩20:00を過ぎても未記録ならバナーが出る。体重も10:30までに未入力なら出る
- **体重** — 1日1回入力。グラフに毎日の体重と7日平均、目標線を表示。タップやなぞりでその日の数値が出る
- **今のペース** — 直近4週間から週あたりの増減を計算し、目標への到達予想日を出す
- **ワンタップ日記** — 運動した／食べすぎ／お酒を1タップで記録し、グラフの下に印を出す
- **この7日間** — 平均体重と先週比、測った日数、サプリの回数、できごとの日数のまとめ
- **記録ストリーク** — 体重を測った連続日数と、サプリを3回とも飲めた連続日数

## 構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 入れ物。manifestとsw.jsを読み込む |
| `app.js` | アプリ本体（`src/` からビルドしたもの。直接編集しない） |
| `src/App.jsx` | 画面とロジックの本体。ここを編集する |
| `src/main.jsx` | 起動とService Workerの登録 |
| `sw.js` | オフライン用。ページはネット優先、アイコン等はキャッシュ優先 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・色・アイコン |

## 更新のしかた

1. `src/App.jsx` を編集
2. `sh src/build.sh` で `app.js` を作り直す
3. `sw.js` の `VERSION` の日付を変える（これを変えないと古い画面が残ることがあります）
4. コミットしてpush。URLを開き直せば反映されます

アイコンを変えるときは `python3 src/icon.py`（Pillowが必要）。
